# Brief: presigned_farm — Runpod/Vast workers with NO cloud credentials inside the pods
(Read /home/user/story-animator/factory/briefs/_common_v2.md first; then cloud/farm/{jobs.py,worker.py,scheduler.py,providers/*,orchestrator.py}, docs/farm.md.)
Problem: external GPU pods currently need AWS access keys (SQS/S3/DynamoDB) and creating keys is not allowed. Build a credential-free "presigned" mode:
- The orchestrator (runs here, has AWS operator creds via `env -u AWS_ACCESS_KEY_ID -u AWS_SECRET_ACCESS_KEY -u AWS_SESSION_TOKEN` + ~/.aws/credentials default profile; region us-east-1; stack 'story-farm', bucket from stack outputs: story-farm-847945017229-us-east-1) packages inputs into S3: code tarball (git archive of HEAD incl. cloud/, factory/, studio/src/data, episodes/<id>/<spec>, assets referenced; NOT node_modules), a library tarball/manifest (library_store files referenced by the spec: use the catalog + spec to select; reuse already-synced objects under s3://<bucket>/library/ if `orchestrator.py sync-library` uploaded them), the episode spec.
- It splits the episode into jobs (cloud/farm/jobs.py), assigns jobs to N pods, and for each pod writes a pod manifest JSON to S3 containing: presigned GET URLs (7 days max) for every input object, presigned PUT URLs for every expected plate PNG (plates/<run>/<shot>/<frame>.png), for per-job logs/manifests, a heartbeat object (PUT, overwritten each minute) and a done marker. Then it launches the pods through the existing providers (Runpod first; RUNPOD_API_KEY is injected by the network proxy for api.runpod.io: send the header with value 'proxy-injected'), passing only MANIFEST_URL (one presigned GET) as env. No AWS keys, no tokens in pods.
- Pod startup (extend cloud/farm/providers/worker_startup.sh or a new presigned_startup.sh): install Blender 4.2.3 (pinned + sha256), fetch the manifest, download inputs with curl, render each job with cloud/blender/render_episode.py (--skip-existing; GPU: Cycles OptiX/CUDA; fail fast if no GPU), PUT each PNG as soon as it's written, PUT heartbeat each minute, PUT logs, PUT the done marker, then idle (the orchestrator terminates it).
- The orchestrator polls S3 (heartbeat/done/plates), re-assigns jobs of dead pods (new pod with a fresh manifest of the missing frames), terminates finished/idle/dead pods via the provider API, enforces budget ($/h and total) and pulls plates locally into episodes/<id>/plates/ when complete. CLI: python3 cloud/farm/presigned.py plan|submit|watch|stop --spec ... --quality preview|final --provider runpod --gpu RTX4090 --workers N --budget USD [--frames A-B] [--dry-run].
- Runpod specifics: read the current REST/GraphQL docs (docs.runpod.io; the repo's providers/runpod.py already implements create/list/terminate) — pick a public CUDA image (e.g. runpod/base or nvidia/cuda runtime), containerDiskInGb large enough for Blender+library (~40), cloudType SECURE, gpuTypeId for RTX 4090 ('NVIDIA GeForce RTX 4090'), dockerArgs/startup via env + a bootstrap command.
