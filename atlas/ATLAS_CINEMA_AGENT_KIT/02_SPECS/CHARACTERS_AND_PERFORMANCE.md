# Digital actors and performance

Asset quality is the limiting factor. A text prompt plus Blender alone does not generate film-realistic humans. Use legally acquired base meshes, groom, calibrated skin shaders, clothing and prepared rigs; optional Faceit/Auto-Rig Pro adapters after compatibility tests. Motion capture or licensed motion libraries for believable body acting. Speech-to-viseme must align to generated voice at phoneme timestamps, not just naive volume-driven mouth opening.

## Minimum implementation

Import character/rig, validate hierarchy and coordinate units, action library mapping, retarget compatible rigs, blend NLA, add gaze, micro-expressions, blinking, head moves, breathing, pauses and gestures. Support deterministic actions and contacts. Annotate each acting action with timing and intent. Use separate close-up quality review for skin, eyes, mouth, teeth, hair, cloth, shadows, facial shape, lip sync and temporal jitter.

## Realism gate

For photorealistic speaking close-ups require verified quality assets and actual tested performance rig; else use stylized actors, silhouettes, wider shots, or clearly scoped hybrid footage approaches. Never market a generic animated avatar as indistinguishable from real humans.
